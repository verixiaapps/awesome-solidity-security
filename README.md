## 🛡️ Common Vulnerabilities

- Reentrancy (Critical) — External call before state update
- Oracle Manipulation (Critical) — Price feed manipulation via flash loans
- Access Control (High) — Improper permission checks
- Integer Overflow (High) — Arithmetic overflow/underflow
- Front-running (Medium) — Transaction ordering dependency

## 📚 Secure Patterns

- Checks-Effects-Interactions — State changes before external calls
- Pull-over-Push — Users withdraw instead of contract pushing
- Emergency Stop — Pause functionality for critical flaws
